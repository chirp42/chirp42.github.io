# chirp42

个人站点

## 当前状态

**v0.6.1 — 两种练习模式。** A / B / C 三级可切换（683 / 1143 / 1282 题）。练习分两种模式：**顺序模式**接着上次的位置做、退出保留进度，可随时用「清空答题」清零；**随机模式**每次进入都重新打乱并清空上一轮。练习页有答题卡（按本轮顺序编号，可点任意格跳题），即时判分，作答记录与错题本保存在本机（刷新不丢），支持导出 / 导入备份。

## 仓库内容

```
.
├── index.html       站点首页
├── quiz/            题库练习应用（原生 JS，无构建）
│   ├── index.html
│   ├── app.js
│   └── style.css
└── data/
    ├── quiz/           原始题库 PDF（数据来源）
    ├── questions.json  1375 题全集
    ├── levels.json     级别 -> 题目 id 映射
    └── meta.json       版本、题量、章节
```

## 数据来源

当前题库为 CRAC《业余无线电台操作技术能力验证题库（2025 年版）》。产物为 `data/` 下的三个 JSON，随仓库发布。
